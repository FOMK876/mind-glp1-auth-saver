# glp1-saver

**Date:** 2026-10-11 (UTC)

## What it does
`glp1-saver` is a simple React web app that generates a pre‑authorization letter for GLP‑1 medication expenses. Users fill in a few fields (patient name, prescriber, insurer, etc.) and instantly receive a formatted letter they can copy or download.

## How to run
```bash
# 1️⃣ Clone the repository
git clone https://github.com/yourusername/glp1-saver.git
cd glp1-saver

# 2️⃣ Install dependencies and start
npm install
npm start
```
The app will be available at `http://localhost:3000`.
